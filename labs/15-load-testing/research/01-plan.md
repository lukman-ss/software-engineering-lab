# Research Plan

## Research Topic
Load Testing and Performance Assessment in Software Systems

## Objective
To investigate load testing methodologies, tools, and best practices, and apply these concepts to determine performance limits, specifically addressing the "Booking Bengkel" scenario.

## Research Questions
1. What are the core types of performance tests (Load, Stress, Spike, Soak)?
2. What system metrics must be monitored during load testing, and why are P95/P99 percentiles preferred over averages?
3. Which tools are standard for API and system load testing?
4. How to plan a load test for the "Booking Bengkel" system (endpoints, virtual users, metrics, bottleneck isolation, and P95 latency investigation)?

## Search Strategy
- Query authoritative documentation (k6, JMeter, Azure/AWS).
- Investigate industry standards for load testing metrics and percentiles.
- Identify bottleneck diagnosis patterns in distributed systems.

## Expected Primary Sources
- Grafana k6 Official Documentation
- Microsoft Azure Load Testing Documentation
- Apache JMeter Documentation

## Risks / Unknowns
- Specific infrastructure limits for the "Booking Bengkel" application are not defined; testing recommendations must remain architectural and methodological.
