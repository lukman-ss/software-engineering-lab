if rec.Status == StatusSuperseded {
    if rec.SupersededBy == 0 {

    } else {
        replacement, exists := recordMap[rec.SupersededBy]

LIMITATIONS 20 / 24
Batas Pembuktian Implementasi

Parser Regex Ketat

Parser mengasumsikan heading persis # 1. Judul dan section H2. Format Markdown bebas atau sintaks non-standar belum didukung.

Model Data In-Memory

Implementasi memvalidasi string Markdown di memori. Belum terhubung otomatis ke traversal disk rekursif atau hook Git.

Linter menjamin integritas struktural silsilah, tetapi tidak dapat menilai apakah argumen bisnis di dalam ADR tersebut secara teknis tepat.
