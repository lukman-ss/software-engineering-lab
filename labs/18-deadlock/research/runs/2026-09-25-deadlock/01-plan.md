# Research Topic
Deadlock — Kenapa Dua Transaksi yang Benar Bisa Saling Mengunci Selamanya?

# Objective
Memahami penyebab, pencegahan, deteksi, dan penanganan deadlock pada transaksi database.

# Research Questions
1. Apa itu deadlock dalam konteks database?
2. Bagaimana database engine (seperti PostgreSQL dan SQL Server) mendeteksi dan menangani deadlock?
3. Apa penyebab paling umum dari deadlock?
4. Bagaimana cara mengurangi dan menangani dampak deadlock di sisi aplikasi?

# Search Strategy
1. Kueri dokumentasi resmi PostgreSQL untuk perilaku locking dan deadlock.
2. Kueri dokumentasi resmi SQL Server untuk arsitektur penanganan deadlock.
3. Bandingkan metode pencegahan dari sumber-sumber tier 1.

# Expected Primary Sources
1. PostgreSQL Official Documentation
2. Microsoft SQL Server Documentation

# Risks / Unknowns
- Dokumentasi MySQL memblokir crawler, sehingga dialihkan ke dokumentasi SQL Server dan PostgreSQL sebagai referensi utama.
