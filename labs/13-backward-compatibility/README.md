# Lab 13: Backward Compatibility

## Objective
Mengembangkan sistem lama yang berjalan di production tanpa merusak client, service, atau worker yang masih bergantung pada contract lama (Database & API).

## Learning Outcomes
- Memahami konsep Backward Compatibility dan pola Expand-Migrate-Contract.
- Mampu mengeksekusi Zero-Downtime Database Schema Migration.
- Membuat API backwards compatible design pattern (seperti model Stripe).
- Strategi deployment aman di environment rolling-deployment dan rollback yang robust.
