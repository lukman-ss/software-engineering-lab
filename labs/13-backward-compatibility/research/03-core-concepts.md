# Core Concepts

## Claim 1: Definisi Backward Compatibility
Evidence: Backward compatibility memastikan client lama masih bisa beroperasi dengan versi software atau API yang baru. 
Source: Parallel Change (Martin Fowler)
URL: https://martinfowler.com/bliki/ParallelChange.html
Confidence: HIGH

## Claim 2: Backward vs Forward Compatibility
Evidence: Backward compatibility = sistem baru menerima input format lama. Forward compatibility = sistem lama bisa menerima/mengabaikan input dengan format baru tanpa error.
Source: Stripe API Versioning
URL: https://stripe.com/blog/api-versioning
Confidence: HIGH

## Claim 3: Breaking Changes
Evidence: Perubahan nama kolom, penghapusan resource, merubah return type, menambah parameter wajib (required).
Source: Stripe API Versioning
URL: https://stripe.com/blog/api-versioning
Confidence: HIGH
